# 开源产品

Structure 的开源产品全部公开于 [structure-projects](https://github.com/structure-projects) 组织，涵盖基础框架、云原生平台、前端与 AI 工具等。以下仅收录定义清晰的产品。

## 基础框架

| 项目 | 定位 | 最新版本 |
|------|------|---------|
| [Structure Boot](/products/open-source/structure-boot) | 基于 Spring Boot 的快速开发框架，开箱即用的 Starter 组件 | 1.5.0 |
| [Structure Infra](/products/open-source/structure-infra) | 基于 DDD 的基础设施抽象层（仓储、事件、任务、流式路由） | 1.3.1 |
| [Structure Security](/products/open-source/structure-security) | 企业级安全认证授权框架（JWT / RBAC / OAuth2 / Basic Auth） | 1.1.5 |
| [Structure Datascope](/products/open-source/structure-datascope) | 数据范围管理框架（行级 + 列级数据权限） | 1.0.3 |
| [structure-job](https://github.com/structure-projects/structure-job) | 调度中心 | 2.0.1 |
| [structure-gateway](https://github.com/structure-projects/structure-gateway) | API 网关 | 1.0.6 |
| [structure-message](https://github.com/structure-projects/structure-message) | 消息中心 | — |
| [structure-general](https://github.com/structure-projects/structure-general) | 通用能力中心 | — |
| [structure-netty](https://github.com/structure-projects/structure-netty) | Netty 网络通信框架 | — |
