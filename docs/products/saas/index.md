# SaaS 产品

Structure 的 SaaS 产品为**闭源商业化解决方案**，以私有仓库形式维护，主要面向企业提供业务能力服务。按解决方案分组如下。

## 电商交易解决方案

以 `structure-shop` 为根仓库的电商平台，涵盖交易全链路。

| 中心 | 定位 |
|------|------|
| structure-shop | 电商平台根仓库，统一编排各领域中心 |
| structure-product | 商品中心 |
| structure-order | 订单中心 |
| structure-pay | 支付中心 |
| structure-trade | 交易中心 |
| structure-seller | 卖家中心 |
| structure-inventory | 库存中心 |
| structure-delivery | 配送中心 |
| structure-fulfillment | 履约中心 |
| structure-benefit | 权益中心 |
| structure-fund | 资金中心 |
| structure-integration | 集成中心 |
