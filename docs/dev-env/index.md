# 开发环境配置

本栏目提供 Structure 生态常用开发语言与工具链的环境配置指南，帮助开发者快速搭建一致的本地开发环境。

## 环境指南

| 页面 | 说明 |
|------|------|
| [Go 环境](/dev-env/go) | Go 安装、GOROOT/GOPATH 配置、Go Modules 与 GOPROXY |
| [gvm 详解](/dev-env/go-gvm) | gvm 多版本管理进阶指南：版本切换、pkgset 隔离、常见问题 |
| [Node.js 环境](/dev-env/node) | nvm 多版本管理 + nrm 镜像源切换 |
| [JDK / Maven](/dev-env/jdk-maven) | SDKMAN 管理 JDK 与 Maven，阿里云镜像源配置 |
| [Python 环境](/dev-env/python) | venv / conda / virtualenv / Poetry 虚拟环境管理 |
| [Conda 详解](/dev-env/python-conda) | Conda 环境与包管理进阶指南 |

## 说明

以上内容源自 [structure-pro](https://github.com/structure-projects/structure-pro) 项目的开发环境文档，覆盖 macOS / Linux / Windows 三大平台，适用于 Structure Boot、Structure Cloud 及各类微服务项目的本地开发。
