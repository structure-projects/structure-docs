# 社区介绍

Structure（结构化开发）是一个面向企业级开发者的开源社区，秉持「结构化开发，为规范而生」的理念，致力于推动企业级开发的标准化与高效协作。

## 社区定位

- 开放、协作、创新的开发者社区
- 聚合开源框架、组件与行业解决方案
- 同时提供开源产品与闭源 SaaS 服务

## 产品体系

Structure 社区的产品分为两类，详见 [产品中心](/products/)：

- **开源产品**：框架、组件、平台工具，公开于 GitHub，可自由使用
- **SaaS 产品**：闭源商业化解决方案，面向企业提供业务能力服务
